# Uma Trainer Guide

우마무스메 SSR 덱, 스킬, 트레이너 가이드, 핑크스킬 진화 선택을 관리하는 정적 웹앱입니다.

현재 배포 기준: V5.4 WEB


## V5.4 변경
- 웹 배포본에 남아 있던 중복 레거시 스크립트를 제거해 V5.3 친구 카드 이벤트 보강 로직이 실제로 실행되도록 수정
- 친구 카드 레어 스킬의 자동 획득/결과 기록 카운트 정상화
- SSR 카드 DB 각 카드에 현재 육성 조건 기준 추천 별점/적합 스킬 수 표시
- SSR 카드 DB에 추천순 정렬 버튼 추가
- 진화 스킬은 현재 덱에서 실제 획득 체크한 레어 스킬 또는 선택한 육성 우마무스메의 레어 스킬에 원본이 있을 때만 선택 가능
- 원본 레어 스킬이 없으면 진화 선택지를 비활성화하고 '선택 불가' 표시
